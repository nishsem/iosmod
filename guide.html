1

Install Configuration Profile

Download and install the configuration profile to enable app installation on your device.

Note: This method works on iOS 17 and below. For iOS 18, you'll need to wait for a compatible version.

Download .mobileconfig
2

Trust the Certificate

After installing the profile, you need to trust the certificate:

  1. Go to Settings > General
  2. Scroll down and tap on "VPN & Device Management"
  3. Find the certificate and tap "Trust"

Important: Make sure to trust the certificate in both the VPN & Device Management section and the Profile section.

3

Install eSign

Download and install the eSign app to manage your IPA files. eSign is a powerful tool that allows you to:

  • Install IPA files directly on your device
  • Manage app certificates
  • Resign apps when needed
  • Install multiple apps at once
Download eSign.ipa
4

Open eSign and Import IPA

Follow these steps to install your apps:

  1. Open the eSign app
  2. Tap the "+" button to import IPA files
  3. Select your IPA file from Files or Downloads
  4. Wait for the installation to complete

Tip: You can install multiple IPA files at once by selecting them all before tapping the install button.

Frequently Asked Questions

Q: Do I need to jailbreak my device?

A: No, this method works without jailbreak. It uses Apple's enterprise certificate system.

Q: How long will the apps stay installed?

A: Apps will remain installed as long as the certificate is valid. We provide new certificates when needed.

Q: Is this method safe?

A: Yes, this method is safe as it uses official Apple systems. However, always download apps from trusted sources.

Q: Will this work on iOS 18?

A: Currently, this method is compatible with iOS 17 and below. For iOS 18, you'll need to wait for a compatible version.
